# Значок «Яндекс Бэкап» для macOS

Приложение показывает состояние фонового резервного копирования, дату последней
успешной копии и текущий прогресс. Оно работает в строке меню без отдельного окна
и без значка в Dock. Копирование выполняет служба Python: закрытие значка её не
останавливает.

Меню позволяет запросить копирование, поставить его на паузу или возобновить,
открыть исходную папку, Яндекс.Диск, журнал и окно настроек. В настройках можно
выбрать папку и интервал копирования от 1 до 1440 минут; изменения вступают в силу
при следующем запуске. Остальные параметры сохраняются. Пауза применяется
после завершения текущих передач. В режиме паузы ручной запуск недоступен; сначала выберите
«Возобновить».

## Сборка

Нужны macOS 13 или новее и Apple Command Line Tools. Внешние зависимости отсутствуют.

```sh
bash macos/build_menu_app.sh "/absolute/path/Yandex Backup.app"
```

Запуск с нестандартным каталогом конфигурации:

```sh
open "/absolute/path/Yandex Backup.app" --args --config-dir "/absolute/path/config"
```

По умолчанию используется `~/Library/Application Support/YandexBackup`.

## Протокол со службой

- `config.json`: приложение показывает и изменяет `source` и `interval_seconds`,
  сохраняя остальные поля при атомарной записи. Для дополнительных параметров
  файл можно редактировать вручную; содержимое файла с токеном приложение не читает.
- `status.json`: `state`, `message`, `last_success` (ISO 8601), `running` и
  `progress` с полями `transferred`, `total`, `files_completed`, `files_total`, `percent`,
  опционально `speed_bytes_per_second` и `eta_seconds`.
- `paused`: наличие файла включает паузу. Возобновление удаляет только этот файл.
- `run-now`: атомарно создаваемый запрос; служба удаляет его после приёма запроса.
- `backup.log`: журнал, открываемый через TextEdit.

Статус обновляется каждые две секунды. Кратковременно неполный JSON не заменяет
предыдущее состояние. Статус старше 30 секунд помечается как устаревший.
Служба должна регулярно обновлять статус во время работы и ожидания.
Потеря связи с Яндекс.Диском и отсутствие связи с фоновой службой показываются отдельно.

Приложение не читает файл с токеном и не запускает или останавливает службу
самостоятельно. Каталог и файлы сигналов создаются с ограниченными правами.
